# Photography Website

## Overview
This project is a simple static photography website built with HTML and CSS. The page uses a full-screen background image and a sliding sidebar menu that can be opened or closed from the left side of the screen.

## Features
- Full-screen landing page with a photography background
- Interactive sidebar menu with a toggle button
- Navigation links for Gallery, Shortcuts, Exhibits, Events, Store, Contact, and Feedback
- Social media icons in the sidebar
- Smooth visual transitions for opening and closing the menu

## Project Structure
- index.html: Main HTML structure of the website
- css/style.css: Styling, layout, background image, and sidebar animation
- Images/: Folder containing the images used by the project

## Technologies Used
- HTML5
- CSS3
- Font Awesome icons
- Google Fonts (Poppins)

## Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Launch index.html in your browser to view the website.

## Usage
- Click the hamburger icon to open the sidebar menu.
- Click the close icon to hide the sidebar.
- Use the navigation links displayed inside the menu.

## Notes
The project is a front-end-only website and does not include any backend functionality or database.
